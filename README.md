# aplicação de força

- um jogo que simula uma aplicação de força para direita e para cima em um único corpo de bola  

---
## 📚 Aprendizados
- aplicação de força em um corpo
- uso da p5 e da matter
- entender funcionamento de aplicação de forças no matter

## ⚙️ Funcionalidades
- mover a bola para direita ao clicar no botão de seta para direita 
- mover a bola para cima ao clicar no botão de seta para cimas
- a bola quica nas paredes quando é aplicado força nela

## 🛠️ Stack
- matter.js
- p5.js
- JavaScript
- HTML5
- CSS3

## 🚀 Deploy
1. Clone ou baixe este repositório.

```bash
git clone https://github.com/LucasVeicir/aplicacao-de-forca
```

2. Abra o arquivo `index.html` em seu navegador.
